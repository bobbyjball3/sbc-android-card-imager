# sbc-android-card-imager

Personal project to create sparse SD card image for my opinionated Android SBC device setup. Use or fork as you will - just keep it open source. I'll probably make this somewhat flexible, but my real target is myself, so it may not do what you want, how you want it.

## AI Disclosure
I'm a software dev by trade, but I did use AI. I don't love AI and the probable societal impacts, but it's really a great tool for software devs to accelerate their work, and it lets me do this stuff while still having a bunch of time for my family. If you don't like AI and don't want to use this project, I get it and I wish you well. 

## Some Notes
- I will not include any copyrighted material that is not properly attributed and is not going to get me into legal trouble (I'm not going to include any ROMs or Bios files for instance)
- Where I use other's projects, I'll attribute properly either in this README in [Credits and Attributions](#credits-and-attribution) or in alongside the artifacts in MD files.
- This does what I want, how I want. It's not made for everyone. It's opinionated in a way that lets me rapidly setup or re-setup an android SBC device that I own.
- I'll consider PRs, but I'm not promising any timeline for response, reviews, etc. If what you're submitting isn't something I want to maintain or include, I'll politely decline and you're welcome to fork this - just keep it open source
